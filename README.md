     1|# 🎐 風鈴 v0.11 — Wind Chime Simulator
     2|
     3|A beautiful wind chime simulator for your desktop.
     4|
     5|一款優美的桌面風鈴模擬器，基於 Web Audio API 打造，完全離線使用。模擬風鈴隨機敲擊的聲音，配合玻璃質感 UI 與動態光球視覺效果，創造永不重複的聽覺體驗。
     6|
     7|> ⚠️ **注意**：本軟體由 AI 編程生成，請在使用前自行評估程式碼安全性，不保證完全無缺陷。
     8|
     9|## ✨ 特色
    10|
    11|- 🎼 **場景模板系統** — 四種風格一鍵切換：禪風冥想（和弦思維 Cmaj7/Dm7/Am7）、鄉村花園（G 大調 Gmaj7/Am7/D7）、Jazz Ambient（Melodic Minor CmM7/Fm7/Dm7b5）、星空夜語（D Dorian Dm7/Gmaj7/Em7）
    12|- 🌬️ **自然風效果** — 兩層 Perlin Noise 疊加（週期 8s + 3s），S 曲線對比度拉伸，風速平滑變化驅動敲擊密度與力度
    13|- 🎵 **六種音色**：金屬、玻璃、💎水晶音效（真實 Sample）、陶磁、木質、敲弦（FMSynth 模擬）
    14|- 🌊 **四個段落**：寂靜 → 風起 → 潮湧 → 餘韻，自動循環
    15|- 🌟 **動態光球粒子**：隨音樂波動，視聽一體的沉浸體驗
    16|- 📦 **離線使用**：單一 HTML 檔，無需安裝或網路連線
    17|- 🎚️ **即時控制**：速度滑桿、音量、音色、殘響，切模板時自動同步
    18|

    25|## ⚙️ 核心機制
    26|
    27|### 音符間隔計算鏈（六層疊加）
    28|
    29|```
    30|avgInterval = 1 / (density × 1.8)
    31|
    32|  ① 基底間隔    密度決定平均間隔
    33|  ② 基底搖擺     × [0.5, 1.5]（均勻隨機 ±50%）
    34|  ③ 基速因子     ÷ (bpm / 60)
    35|  ④ 隨機修飾     25% burst (×0.5) | 10% 稀疏 (×2)
    36|  ⑤ 風速因子     × 2^p，p = 1.5 - wind × 5.0
    37|                 無風→慢(p=1.5)，強風→快(p=-3.5)
    38|  ⑥ 安全裁切     clamp [0.1s, 5s]
    39|```
    40|
    41|### 風速系統
    42|
    43|- **Perlin Noise 1D** 兩層疊加（慢層 8s×0.35 + 快層 3s×0.65）
    44|- **S 曲線對比度拉伸**，解決常態分布中間值過多的問題
    45|- 風速（0~1）映射為 **p 值（1.5 ~ -3.5）**，間隔 × 2^p 調變
